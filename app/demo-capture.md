## 通信なしで撮影用記録を用意する

Node.js 22.22.1以上。インストール・APIキーは不要です。追加コードは既存の手配関数を呼び、HTTP応答だけを固定しています。

```sh
node app/create-demo-record.mjs
```

日本時間の翌日18〜22時の欠員を作ります。毎回別の `output/playwright/demo-<UUID>` を作り、既存の承認は消しません。出力されたコマンドを実行します。

```sh
node app/serve.mjs --records "output/playwright/demo-<出力されたUUID>"
```

表示先は http://127.0.0.1:4173 。使用中なら `--port 4175` を加えます。
日付と出力先を固定したいときだけ次を指定できます。

```sh
node app/create-demo-record.mjs --date 2026-09-22 --output output/playwright/rehearsal-1
node --test app/demo-record.test.mjs
```

過去日はCLIが拒否します。同じ日付・出力フォルダの再実行では記録を再利用し、承認を消しません。承認操作を撮り直す場合は新しい出力フォルダを使ってください。

## CLI入力からの通し録画の台本（CLI部分は未収録）

この画面には欠員入力フォームがありません。録画はコマンド入力から始め、途中でブラウザへ移ります。画面録画の対象に秘密情報を置かず、`.env` を開かないでください。
