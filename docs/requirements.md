## 完成の判定

チーム共通の完成条件は [3人での進め方](team-playbook.md) にあります。ここでは作品に合わせて確認できる形にし、提出前にこの順で見ます。

- [ ] デモの1本が最初から最後まで動く（仮データの箇所は明示する）
- [ ] AIが行動を選んでいる箇所を、コードを指して説明できる
- [ ] 1件ごとの記録（入力・選んだ行動・モデル・費用・結果）が残っている
- [ ] 空入力・AIや通信の失敗のときに、利用者へ状態が伝わる
- [ ] 上限に達したら止まり、人へ回る
- [ ] 別のメンバーがREADMEの手順どおりに起動できる
- [ ] 秘密情報と実在の個人情報を含まない（**公開する場合は履歴も**）
- [ ] AIが担う処理と、その限界を口頭で説明できる
- [ ] デモ用のサンプル入力と、予備の録画がある
- [ ] **Qiita/Zenn記事を公開した**（OrcaRouterと「AI HACK」に触れる）
- [ ] 作品が決まったら、固有の条件をここに追記する
