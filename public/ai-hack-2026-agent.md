## OrcaRouterをどう使ったか

今回はスポンサーの [OrcaRouter](https://www.orcarouter.ai/) を利用しました。1つのAPIキーで200以上のモデルを呼べて、OpenAI SDK互換なので `base_url` と `api_key` を差し替えるだけで動きます。

```python
client = OpenAI(
    base_url="https://api.orcarouter.ai/v1",
    api_key=os.environ["ORCAROUTER_API_KEY"],
    max_retries=2,
)
```
